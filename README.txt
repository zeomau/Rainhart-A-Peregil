RAINHART A. PEREGIL — PORTFOLIO WEBSITE

HOW TO RUN
1. Extract the ZIP file.
2. Open the rainhart_portfolio folder in Visual Studio Code.
3. Start Live Server from index.html and open its local website URL. This is needed for the music file to load reliably.
4. The original photo is saved in assets/rainhart.jpg. The website uses the transparent cutout in assets/rainhart-cutout.png.

CUSTOMIZE
- Change your contact email in index.html: search for your-email@example.com.
- Replace the project preview illustrations with screenshots of your real projects if you have them.
- Update the skills, project descriptions, and social links as needed.
